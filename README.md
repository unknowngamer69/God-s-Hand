# God's Hand - CAD

God's Hand is a humanitarian hexacopter drone made to help people during natural and man-made disasters.

This repository contains the CAD design of the drone's body, base plate, and arms. It covers the physical design only. The flight controller and electronics are in a separate project.

## CAD Models

### Main Lower Body

![Main Lower Body](https://cdn.hackclub.com/01a12e18-2d46-73ef-8b6e-2d4ba654fec5/screenshot_2026-10-12_084126.png)

The lower body is part of the main frame. It has holes to attach the other parts.

### Main Upper Body

![Main Upper Body](https://cdn.hackclub.com/01a12e2b-eddc-7fa2-8030-37340384c263/image.png)

The upper body fits on the lower body. Screws hold the two parts together.

### Base Plate

![Base Plate](https://cdn.hackclub.com/01a12e2c-40f6-7c37-920d-c28df9e14d9b/image.png)

The base plate joins the main body to the six arms. It is a separate part to make printing and assembly easier.

### Arm

![Drone Arm](https://cdn.hackclub.com/01a12e2c-b105-7905-96fb-fc7e6ae5df8d/image.png)

The arms are separate parts that attach to the base plate with screws. Carbon fibre rods are planned to keep them light and strong.

## Main Parts

- Main upper body
- Main lower body
- Base plate
- Six arms
- Movable camera mount (planned)

## Design

The body has two parts so it can be opened when needed. The base plate and arms are separate so they are easier to print and replace. Screw holes are used to join the parts.
